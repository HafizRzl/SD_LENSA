# LENSA Phase 1 — Native Kotlin Skeleton Implementation Plan

> **Status (2026-10-18): not started; written against the July desktop beta.** Since then the beta
> gained object tracking, box-extent steering with hysteresis, an all-blocked map fallback, a
> second (road-hazard) detector, two-clip voice joins and a catalog whitelist; the ToF sensor is
> now the **VL53L8CX** (same 8×8 grid). When building, port behaviour from `desktop-beta/`
> (`lensa_rules.py`, `lensa_beta.py`) — it is the source of truth; this plan is the scaffolding.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **SYNCED 2026-07-07 to the validated desktop beta** (`desktop-beta/` is the live reference
> spec — same YAML content, same rules). This plan's code now includes: plain-YAML content
> loading, the `kosong` wording, hazard-aware side-steering (`steer_hazard`/`{elak}`), and the
> `avoid` field. Phase 5 was rewritten around the proven segment-clip voice design.

**Goal:** Stand up a native Android (Kotlin) app that runs the full LENSA navigation pipeline on **mock** inputs and **speaks Bahasa Melayu** through the phone — no head unit, no ML models — with unit tests locking the deterministic safety logic.

**Architecture:** Ports the validated pipeline (live reference: `desktop-beta/`; original Flutter prototype at tag `flutter-reference`) 1:1 to Kotlin. Swappable interfaces (`HeadUnitTransport`, `ObjectDetector`, `OcrService`, `NavigationAgent`, `TtsService`) each have a `Mock`/real seam. The editable `assets/context/**` content layer is copied over unchanged and parsed with SnakeYAML. Loop A (deterministic rules → template phrase → TTS) is fully working on mock data; Loop B (Gemma) and real perception are later phases. See `docs/ARCHITECTURE.md`.

**Tech Stack:** Kotlin, Android SDK (Views + ViewBinding), Kotlin Coroutines + Flow, `org.yaml:snakeyaml`, Android `TextToSpeech`, JUnit4.

## Global Constraints

- Package: `com.lensa` — every file below is under it.
- Project root: `android-app/` (a subfolder of this repo). Flutter code at repo root stays as reference; do not modify it.
- Minimum SDK: **API 26**. Accept Android Studio's wizard defaults for AGP / Kotlin / Gradle versions.
- Phase-1 dependencies added beyond the wizard: **only** `kotlinx-coroutines-android` and `org.yaml:snakeyaml`. No ML, no BLE, no camera libs this phase.
- Default language **Bahasa Melayu (`ms`)**; UI is audio-first and TalkBack-friendly.
- Safety path is **deterministic** — no LLM anywhere in this plan.
- App is **offline** at runtime (Gradle needs internet once to download deps; the app never does).
- Placeholder names inside phrase templates (`{objek}`, `{arah}`, `{jarak}`, `{teks}`) are load-bearing — never rename them.

```kotlin
package com.lensa.model

enum class ObjectPosition {
    LEFT, CENTER, RIGHT;

    /** Key used to look up a spoken direction word in the phrase library. */
    val directionKey: String
        get() = when (this) {
            LEFT -> "left"
            RIGHT -> "right"
            CENTER -> "ahead"
        }

    companion object {
        fun fromString(s: String): ObjectPosition = when (s.lowercase()) {
            "left" -> LEFT
            "right" -> RIGHT
            else -> CENTER
        }
    }
}

enum class NavAction { PROCEED, CAUTION, STOP, STEER_LEFT, STEER_RIGHT, READ }

enum class Urgency {
    LOW, MEDIUM, HIGH;

    companion object {
        fun fromString(s: String): Urgency = when (s.lowercase()) {
            "high" -> HIGH
            "medium" -> MEDIUM
            else -> LOW
        }
    }
}

enum class HeadUnitConnectionState { DISCONNECTED, CONNECTING, CONNECTED, ERROR }
```

```kotlin
package com.lensa.content

import org.yaml.snakeyaml.Yaml

internal fun asDouble(v: Any?, def: Double): Double = (v as? Number)?.toDouble() ?: def
internal fun asInt(v: Any?, def: Int): Int = (v as? Number)?.toInt() ?: def
internal fun asBool(v: Any?, def: Boolean): Boolean = (v as? Boolean) ?: def
internal fun asStr(v: Any?, def: String): String = v?.toString() ?: def

internal fun stringMap(m: Any?): Map<String, String> {
    val out = LinkedHashMap<String, String>()
    if (m is Map<*, *>) m.forEach { (k, v) -> out[k.toString()] = v?.toString() ?: "" }
    return out
}

/** Parses a plain YAML document into a Map (the content files are plain .yaml). */
object YamlBlock {
    fun extract(md: String): Map<*, *> {
        val loaded: Any? = Yaml().load(md)
        return loaded as? Map<*, *> ?: emptyMap<Any, Any>()
    }
}
```

```kotlin
package com.lensa.content

import com.lensa.model.ObjectInfo
import com.lensa.model.ObjectPosition

class ObjectCatalog(private val byClass: Map<String, ObjectInfo>) {
    fun info(c: String): ObjectInfo? = byClass[c]
    fun dangerWeight(c: String): Int = byClass[c]?.dangerWeight ?: 3
    fun label(c: String, lang: String): String {
        val i = byClass[c] ?: return c
        return if (lang == "en") i.en else i.ms
    }

    companion object {
        fun fromMarkdown(md: String): ObjectCatalog {
            val y = YamlBlock.extract(md)
            val list = y["objects"]
            val map = LinkedHashMap<String, ObjectInfo>()
            if (list is Iterable<*>) {
                for (e in list) {
                    if (e !is Map<*, *>) continue
                    val cls = asStr(e["yolo_class"], "")
                    if (cls.isEmpty()) continue
                    map[cls] = ObjectInfo(
                        yoloClass = cls,
                        en = asStr(e["en"], cls),
                        ms = asStr(e["ms"], cls),
                        dangerWeight = asInt(e["danger_weight"], 3),
                    )
                }
            }
            return ObjectCatalog(map)
        }
    }
}

data class DistanceBands(
    val immediateStopBelowM: Double,
    val cautionBelowM: Double,
    val noticeBelowM: Double,
    val ignoreAboveM: Double,
)

class HazardRules(
    val confidenceFloor: Double,
    val bands: DistanceBands,
    val sensitivity: String,
    val movingTowardMultiplier: Double,
) {
    companion object {
        fun fromMarkdown(md: String): HazardRules {
            val y = YamlBlock.extract(md)
            val db = y["distance_bands"] as? Map<*, *>
            fun band(k: String, def: Double) = if (db != null) asDouble(db[k], def) else def
            return HazardRules(
                confidenceFloor = asDouble(y["confidence_floor"], 0.45),
                bands = DistanceBands(
                    immediateStopBelowM = band("immediate_stop_below_m", 1.0),
                    cautionBelowM = band("caution_below_m", 3.0),
                    noticeBelowM = band("notice_below_m", 6.0),
                    ignoreAboveM = band("ignore_above_m", 6.0),
                ),
                sensitivity = asStr(y["sensitivity"], "medium"),
                movingTowardMultiplier = asDouble(y["moving_toward_multiplier"], 1.5),
                // repeat/silence policy lives in AudioStyle (config/audio_output_style.yaml)
            )
        }
    }
}

class PhraseLibrary(
    val directions: Map<String, String>,
    val templates: Map<String, String>,
    val urgencyPrefix: Map<String, String>,
) {
    fun direction(p: ObjectPosition): String = directions[p.directionKey] ?: p.directionKey

    /** Fills a template. Handles both Bahasa Melayu and English placeholder aliases. */
    fun render(
        templateKey: String,
        `object`: String? = null,
        direction: String? = null,
        distance: String? = null,
        text: String? = null,
        avoid: String? = null,
    ): String {
        var t = templates[templateKey] ?: ""
        if (`object` != null) t = t.replace("{objek}", `object`).replace("{object}", `object`)
        if (direction != null) t = t.replace("{arah}", direction).replace("{direction}", direction)
        if (distance != null) t = t.replace("{jarak}", distance).replace("{distance}", distance)
        if (text != null) t = t.replace("{teks}", text).replace("{text}", text)
        if (avoid != null) t = t.replace("{elak}", avoid).replace("{avoid}", avoid)
        return t.trim()
    }

    companion object {
        fun fromMarkdown(md: String): PhraseLibrary {
            val y = YamlBlock.extract(md)
            return PhraseLibrary(
                directions = stringMap(y["directions"]),
                templates = stringMap(y["templates"]),
                urgencyPrefix = stringMap(y["urgency_prefix"]),
            )
        }
    }
}

class OcrRules(

    val prioritise: List<String>,
    val ignoreClutter: Boolean,
    val maxChars: Int,
    val translate: Boolean,

    val prefixEn: String,
) {
    companion object {

                prefixEn = asStr(y["announce_prefix_en"], "Sign"),
            )
        }
    }
}

class SafetyFallback(private val entries: Map<String, Map<String, String>>) {
    fun line(key: String, lang: String): String =
        entries[key]?.get(lang) ?: entries[key]?.get("ms") ?: ""

    companion object {
        fun fromMarkdown(md: String): SafetyFallback {
            val y = YamlBlock.extract(md)
            val out = LinkedHashMap<String, Map<String, String>>()
            y.forEach { (k, v) -> if (v is Map<*, *>) out[k.toString()] = stringMap(v) }
            return SafetyFallback(out)
        }
    }
}
```

```kotlin
package com.lensa.content

import android.content.res.AssetManager

/**
 * Holds every runtime content model. Build it once at startup via [fromAssets];
 * unit tests construct it directly from markdown strings.
 */
class ContentRepository(
    val objects: ObjectCatalog,
    val hazardRules: HazardRules,
    val ocrRules: OcrRules,
    val phrasesMs: PhraseLibrary,
    val phrasesEn: PhraseLibrary,
    val audioStyle: AudioStyle,
    val safety: SafetyFallback,
    val defaults: UserSettings,
    val prompts: AgentPrompts,
) {
    fun phrases(lang: String): PhraseLibrary = if (lang == "en") phrasesEn else phrasesMs

    companion object {
        private const val BASE = "context"

        fun fromAssets(assets: AssetManager): ContentRepository {
            fun read(p: String): String =
                assets.open("$BASE/$p").bufferedReader().use { it.readText() }
            return ContentRepository(
                objects = ObjectCatalog.fromMarkdown(read("rules/object_catalog.yaml")),
                hazardRules = HazardRules.fromMarkdown(read("rules/hazard_priority_rules.yaml")),
                ocrRules = OcrRules.fromMarkdown(read("rules/ocr_reading_rules.yaml")),
                phrasesMs = PhraseLibrary.fromMarkdown(read("language/phrase_library_ms.yaml")),
                phrasesEn = PhraseLibrary.fromMarkdown(read("language/phrase_library_en.yaml")),
                audioStyle = AudioStyle.fromMarkdown(read("config/audio_output_style.yaml")),
                safety = SafetyFallback.fromMarkdown(read("config/safety_fallback.yaml")),
                defaults = UserSettings.fromMarkdown(read("config/user_settings_defaults.yaml")),
                prompts = AgentPrompts(
                    master = read("agents/agent_system_master.md"),
                    layer1 = read("agents/layer1_scene_interpretation.md"),
                    layer2 = read("agents/layer2_hazard_decision.md"),
                    layer3 = read("agents/layer3_instruction_language.md"),
                ),
            )
        }
    }
}
```

```kotlin
package com.lensa.navigation

import com.lensa.content.ContentRepository
import com.lensa.content.DistanceBands
import com.lensa.content.UserSettings
import com.lensa.model.*

/**
 * Deterministic 3-layer navigation logic, fully driven by the content files
 * (hazard rules, object catalog, phrase library). No model — cannot hallucinate.
 */
class RulesNavigationAgent(
    private val content: ContentRepository,
    private val settings: () -> UserSettings,
) : NavigationAgent {

    override suspend fun run(detections: List<Detection>, ocr: OcrResult?): NavigationResult {
        val s = settings()
        val scene = interpret(detections, ocr)     // Layer 1
        val decision = decide(scene, s)            // Layer 2
        val line = language(decision, s)           // Layer 3
        return NavigationResult(decision, line)
    }

    // --- Layer 1: clean up + merge detections into a scene ---
    private fun interpret(ds: List<Detection>, ocr: OcrResult?): Scene {
        val floor = content.hazardRules.confidenceFloor
        val merged = LinkedHashMap<String, SceneItem>()
        for (d in ds.filter { it.confidence >= floor }) {
            val ex = merged[d.yoloClass]
            merged[d.yoloClass] = if (ex == null) {
                SceneItem(d.yoloClass, d.distanceM, d.position, d.movingToward)
            } else {
                val closer = (d.distanceM ?: 1e9) < (ex.distanceM ?: 1e9)
                SceneItem(
                    yoloClass = d.yoloClass,
                    distanceM = if (closer) d.distanceM else ex.distanceM,
                    position = if (closer) d.position else ex.position,
                    movingToward = ex.movingToward || d.movingToward,
                )
            }
        }
        var ocrText: String? = null
        if (ocr != null && ocr.confidence >= content.ocrRules.minConfidence && ocr.text.trim().isNotEmpty()) {
            ocrText = ocr.text.trim()
        }
        return Scene(merged.values.toList(), ocrText)
    }

    // --- Layer 2: pick the one thing to say + the action ---
    private fun decide(scene: Scene, s: UserSettings): HazardDecision {
        val b = content.hazardRules.bands
        val items = scene.items

        if (items.isEmpty()) {
            if (scene.ocrText != null && !s.ocrOnDemand) {
                return HazardDecision(NavAction.READ, urgency = Urgency.LOW, ocrText = scene.ocrText)
            }
            return HazardDecision(NavAction.PROCEED, urgency = Urgency.LOW)
        }

        // Immediate-stop override.
        var stopItem: SceneItem? = null
        for (it in items) {
            val d = it.distanceM ?: continue
            if (d <= b.immediateStopBelowM) {
                if (stopItem == null || d < (stopItem!!.distanceM ?: 1e9)) stopItem = it
            }
        }
        stopItem?.let {
            return HazardDecision(NavAction.STOP, it.yoloClass, it.position, it.distanceM, Urgency.HIGH)
        }

        // Score everything and pick the highest.
        val sm = sensMult(s.hazardSensitivity)
        var best: SceneItem? = null
        var bestScore = -1.0
        for (it in items) {
            val f = proximity(it.distanceM, b)
            val score = content.objects.dangerWeight(it.yoloClass) * f *
                (if (it.movingToward) content.hazardRules.movingTowardMultiplier else 1.0) * sm
            if (score > bestScore) { bestScore = score; best = it }
        }
        val chosen = best
        if (chosen == null || bestScore <= 0.001) {
            return HazardDecision(NavAction.PROCEED, urgency = Urgency.LOW)
        }

        val d = chosen.distanceM
        val action: NavAction
        val urg: Urgency
        when {
            d != null && d <= b.cautionBelowM -> { action = NavAction.CAUTION; urg = Urgency.MEDIUM }
            d != null && d <= b.noticeBelowM -> { action = NavAction.CAUTION; urg = Urgency.LOW }
            d == null -> { action = NavAction.CAUTION; urg = Urgency.LOW }
            else -> return HazardDecision(NavAction.PROCEED, urgency = Urgency.LOW)
        }

        val leftBlocked = items.any {
            it.position == ObjectPosition.LEFT && (it.distanceM == null || it.distanceM <= b.noticeBelowM)
        }
        val rightBlocked = items.any {
            it.position == ObjectPosition.RIGHT && (it.distanceM == null || it.distanceM <= b.noticeBelowM)
        }
        val close = d != null && d <= b.cautionBelowM   // only side-steer for a genuinely near hazard

        // Steer AWAY from the hazard when a side is open. `position` stays the hazard's real
        // side (for phrasing); `avoid` is where to move.
        if (chosen.position == ObjectPosition.CENTER) {
            if (!leftBlocked) {
                return HazardDecision(NavAction.STEER_LEFT, chosen.yoloClass, ObjectPosition.CENTER, d, urg,
                    avoid = ObjectPosition.LEFT)
            } else if (!rightBlocked) {
                return HazardDecision(NavAction.STEER_RIGHT, chosen.yoloClass, ObjectPosition.CENTER, d, urg,
                    avoid = ObjectPosition.RIGHT)
            }
        } else if (close && chosen.position == ObjectPosition.LEFT && !rightBlocked) {
            return HazardDecision(NavAction.STEER_RIGHT, chosen.yoloClass, ObjectPosition.LEFT, d, urg,
                avoid = ObjectPosition.RIGHT)
        } else if (close && chosen.position == ObjectPosition.RIGHT && !leftBlocked) {
            return HazardDecision(NavAction.STEER_LEFT, chosen.yoloClass, ObjectPosition.RIGHT, d, urg,
                avoid = ObjectPosition.LEFT)
        }

        return HazardDecision(action, chosen.yoloClass, chosen.position, d, urg)
    }

    // --- Layer 3: turn the decision into one short spoken line ---
    private fun language(dec: HazardDecision, s: UserSettings): String {
        val lib = content.phrases(s.language)
        val obj = dec.yoloClass?.let { content.objects.label(it, s.language) } ?: ""
        val dist = dec.distanceM?.let { Math.round(it).toString() } ?: ""

        val base = when (dec.action) {
            NavAction.PROCEED -> lib.render("clear")
            NavAction.STOP -> lib.render("stop", `object` = obj)
            NavAction.CAUTION -> if (dec.distanceM != null) {
                lib.render(
                    "detection",
                    `object` = obj,
                    direction = lib.direction(dec.position ?: ObjectPosition.CENTER),
                    distance = dist,
                )
            } else {
                lib.render(
                    "caution",
                    `object` = obj,
                    direction = lib.direction(dec.position ?: ObjectPosition.CENTER),
                )
            }
            NavAction.STEER_LEFT, NavAction.STEER_RIGHT -> {
                val avoid = dec.avoid
                    ?: if (dec.action == NavAction.STEER_LEFT) ObjectPosition.LEFT else ObjectPosition.RIGHT
                val avoidWord = lib.direction(avoid)
                val hazardWord = lib.direction(dec.position ?: ObjectPosition.CENTER)
                val t = if (dec.distanceM != null) {
                    lib.render("steer_hazard", `object` = obj, direction = hazardWord,
                        distance = dist, avoid = avoidWord)
                } else {
                    lib.render("steer_hazard_nodist", `object` = obj, direction = hazardWord,
                        avoid = avoidWord)
                }
                if (t.isEmpty()) lib.render("steer", direction = avoidWord) else t
            }
            NavAction.READ -> lib.render("ocr", text = dec.ocrText ?: "")
        }

        if (dec.urgency == Urgency.HIGH &&
            (dec.action == NavAction.CAUTION || dec.action == NavAction.STEER_LEFT || dec.action == NavAction.STEER_RIGHT)
        ) {
            val p = (lib.urgencyPrefix["high"] ?: "").trim()
            if (p.isNotEmpty()) return "$p $base".trim()
        }
        return base
    }

    private fun proximity(d: Double?, b: DistanceBands): Double {
        if (d == null) return 0.2
        if (d <= b.immediateStopBelowM) return 1.0
        if (d >= b.ignoreAboveM) return 0.0
        return ((b.ignoreAboveM - d) / (b.ignoreAboveM - b.immediateStopBelowM)).coerceIn(0.0, 1.0)
    }

    private fun sensMult(s: String): Double = when (s) {
        "low" -> 0.8
        "high" -> 1.25
        else -> 1.0
    }
}
```

```kotlin
import android.content.Context
import android.speech.tts.TextToSpeech
import android.util.Log
import java.util.Locale
import kotlin.coroutines.resume
import kotlinx.coroutines.suspendCancellableCoroutine

interface TtsService {
    suspend fun init()
    suspend fun speak(text: String, interrupt: Boolean = false)
    suspend fun stop()
    fun setLanguage(lang: String)       // "ms" | "en"
    fun setRate(rate: Double)           // 1.0 = normal
    fun dispose()
}

private fun localeFor(lang: String): Locale =
    if (lang == "en") Locale.US else Locale("ms", "MY")

/** Real TTS via the device engine. Falls back to the platform default voice if no ms-MY voice. */
class AndroidTtsService(private val context: Context) : TtsService {
    private var tts: TextToSpeech? = null

    override suspend fun init() = suspendCancellableCoroutine { cont ->
        var engine: TextToSpeech? = null
        engine = TextToSpeech(context) { status ->
            if (status == TextToSpeech.SUCCESS) {
                engine?.language = localeFor("ms")
                engine?.setSpeechRate(0.5f)
            } else {
                Log.w("tts", "init failed: $status")
            }
            if (cont.isActive) cont.resume(Unit)
        }
        tts = engine
        cont.invokeOnCancellation { engine?.shutdown() }
    }

    override suspend fun speak(text: String, interrupt: Boolean) {
        if (text.isEmpty()) return
        val mode = if (interrupt) TextToSpeech.QUEUE_FLUSH else TextToSpeech.QUEUE_ADD
        tts?.speak(text, mode, null, text.hashCode().toString())
    }

    override suspend fun stop() { tts?.stop() }

    override fun setLanguage(lang: String) { tts?.language = localeFor(lang) }

    // TextToSpeech rate: 1.0f = normal; content speaking_rate 1.0 -> 0.5f baseline (matches Flutter tuning).
    override fun setRate(rate: Double) {
        tts?.setSpeechRate((rate * 0.5).toFloat().coerceIn(0.1f, 3.0f))
    }

    override fun dispose() { tts?.stop(); tts?.shutdown(); tts = null }
}

/** No-audio TTS that just logs — useful for silent testing. */
class LogTtsService : TtsService {
    override suspend fun init() {}
    override suspend fun speak(text: String, interrupt: Boolean) { Log.d("TTS", text) }
    override suspend fun stop() {}
    override fun setLanguage(lang: String) {}
    override fun setRate(rate: Double) {}
    override fun dispose() {}
}
```

```kotlin
package com.lensa.pipeline

import android.util.Log
import com.lensa.audio.TtsService
import com.lensa.content.ContentRepository
import com.lensa.content.UserSettings
import com.lensa.model.*
import com.lensa.navigation.NavigationAgent
import com.lensa.perception.ObjectDetector
import com.lensa.perception.OcrService
import com.lensa.transport.HeadUnitTransport
import kotlinx.coroutines.*
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.update

/** Orchestrates capture -> detect -> refine -> agent -> speak, exposing state to the UI. */
class PipelineController(
    private val content: ContentRepository,
    private val settings: () -> UserSettings,
    private val transport: HeadUnitTransport,
    private val detector: ObjectDetector,
    private val ocr: OcrService,
    private val agent: NavigationAgent,
    private val tts: TtsService,
    private val scope: CoroutineScope,
) {
    data class UiState(
        val connection: HeadUnitConnectionState = HeadUnitConnectionState.DISCONNECTED,
        val currentLine: String = "",
        val running: Boolean = false,
    )

    private val _state = MutableStateFlow(UiState())
    val state: StateFlow<UiState> = _state

    private var lastSensor: SensorReading? = null
    private var lastSpoken = ""
    private var lastSpokenAt = 0L
    private var requestOcr = false
    private var ttsReady = false
    private val jobs = mutableListOf<Job>()

    suspend fun start() {
        if (_state.value.running) return
        _state.update { it.copy(running = true) }
        ensureTts()
        tts.setLanguage(settings().language)
        tts.setRate(settings().speakingRate)
        jobs += scope.launch { transport.connection.collect { onConn(it) } }
        jobs += scope.launch { transport.sensor.collect { lastSensor = it } }
        jobs += scope.launch { transport.frames.collect { onFrame(it) } }
        transport.connect()
    }

    suspend fun stop() {
        _state.update { it.copy(running = false) }
        jobs.forEach { it.cancel() }; jobs.clear()
        transport.disconnect()
        tts.stop()
    }

    /** Ask for a one-off OCR read on the next frame. */
    fun requestOcrRead() { requestOcr = true }

    private suspend fun ensureTts() {
        if (ttsReady) return
        tts.init(); ttsReady = true
    }

    /** Speak a short confirmation (e.g. a button tap). Interrupts current speech. */
    suspend fun announce(line: String) {
        if (line.isEmpty()) return
        ensureTts()
        tts.setLanguage(settings().language)
        tts.speak(line, interrupt = true)
    }

    private fun onConn(s: HeadUnitConnectionState) {
        _state.update { it.copy(connection = s) }
        if (s == HeadUnitConnectionState.DISCONNECTED && _state.value.running) {
            scope.launch { speak(content.safety.line("connection_lost", settings().language), interrupt = true) }
        }
    }

    private suspend fun onFrame(frame: CameraFrame) {
        try {
            var dets = detector.detect(frame)
            dets = applyTof(dets, lastSensor)

            var ocrRes: OcrResult? = null
            if (requestOcr || !settings().ocrOnDemand) {
                ocrRes = ocr.recognize(frame)
                requestOcr = false
            }

            val result = agent.run(dets, ocrRes)
            _state.update { it.copy(currentLine = result.spokenLine) }
            maybeSpeak(result)
        } catch (e: Exception) {
            Log.d("pipeline", "error: ${e.message}")
        }
    }

    /** Refine the nearest dead-ahead detection with the latest ToF distance. */
    private fun applyTof(dets: List<Detection>, r: SensorReading?): List<Detection> {
        if (r == null) return dets
        var idx = -1
        var best = Double.MAX_VALUE
        dets.forEachIndexed { i, d ->
            if (d.position == ObjectPosition.CENTER) {
                val dist = d.distanceM ?: Double.MAX_VALUE
                if (dist < best) { best = dist; idx = i }
            }
        }
        if (idx < 0) return dets
        return dets.toMutableList().also { it[idx] = it[idx].copy(distanceM = r.distanceM) }
    }

    private suspend fun maybeSpeak(r: NavigationResult) {
        val style = content.audioStyle
        val line = r.spokenLine.trim()
        if (line.isEmpty()) return

        val high = r.decision.urgency == Urgency.HIGH
        val now = System.currentTimeMillis()
        val sinceMs = now - lastSpokenAt
        val repeatMs = (if (high) style.repeatHighUrgencyEveryS else style.repeatNormalEveryS) * 1000L

        if (line == lastSpoken && !style.speakWhenSceneUnchanged && sinceMs < repeatMs) return
        if (sinceMs < style.minGapBetweenLinesS * 1000 && !high) return

        speak(line, interrupt = high && style.interruptOnHighUrgency)
    }

    private suspend fun speak(line: String, interrupt: Boolean = false) {
        if (line.isEmpty()) return
        lastSpoken = line
        lastSpokenAt = System.currentTimeMillis()
        tts.speak(line, interrupt = interrupt)
    }
}
```

```kotlin
package com.lensa.di

import android.content.Context
import com.lensa.audio.AndroidTtsService
import com.lensa.audio.LogTtsService
import com.lensa.audio.TtsService
import com.lensa.content.ContentRepository
import com.lensa.navigation.RulesNavigationAgent
import com.lensa.perception.MockObjectDetector
import com.lensa.perception.MockOcrService
import com.lensa.pipeline.PipelineController
import com.lensa.transport.MockTransport
import kotlinx.coroutines.CoroutineScope

/** Manual composition root (mirrors di.dart). Builds the object graph from AppConfig. */
class AppGraph(context: Context, scope: CoroutineScope) {
    val content = ContentRepository.fromAssets(context.assets)
    val settings = content.defaults   // mutable UserSettings; Settings UI edits this later

    private val transport = MockTransport()
    private val detector = MockObjectDetector()
    private val ocr = MockOcrService()
    private val agent = RulesNavigationAgent(content) { settings }
    val tts: TtsService = if (AppConfig.useLogTts) LogTtsService() else AndroidTtsService(context)

    val pipeline = PipelineController(content, { settings }, transport, detector, ocr, agent, tts, scope)

    fun dispose() {
        tts.dispose()
        transport.dispose()
    }
}
```

- [ ] **Step 4: Write `MainActivity.kt`**
```kotlin
package com.lensa.ui

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity
import androidx.lifecycle.Lifecycle
import androidx.lifecycle.lifecycleScope
import androidx.lifecycle.repeatOnLifecycle
import com.lensa.databinding.ActivityMainBinding
import com.lensa.di.AppGraph
import kotlinx.coroutines.launch

class MainActivity : AppCompatActivity() {
    private lateinit var binding: ActivityMainBinding
    private lateinit var graph: AppGraph

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityMainBinding.inflate(layoutInflater)
        setContentView(binding.root)
        graph = AppGraph(applicationContext, lifecycleScope)

        binding.btnStartStop.setOnClickListener {
            lifecycleScope.launch {
                if (graph.pipeline.state.value.running) graph.pipeline.stop()
                else graph.pipeline.start()
            }
        }
        binding.btnOcr.setOnClickListener { graph.pipeline.requestOcrRead() }
        binding.btnDescribe.setOnClickListener {
            // Loop B (Gemma) is a later phase; speak a placeholder for now.
            lifecycleScope.launch { graph.pipeline.announce("Penerangan pemandangan belum tersedia") }
        }

        lifecycleScope.launch {
            repeatOnLifecycle(Lifecycle.State.STARTED) {
                graph.pipeline.state.collect { st ->
                    binding.txtStatus.text = "Status: ${st.connection}"
                    if (st.currentLine.isNotEmpty()) binding.txtLine.text = st.currentLine
                    binding.btnStartStop.text = if (st.running) "Stop" else "Start"
                }
            }
        }
    }

    override fun onDestroy() {
        super.onDestroy()
        graph.dispose()
    }
}
```

A native Kotlin LENSA that runs the real navigation logic on mock data and **speaks correct Bahasa Melayu guidance**, with the safety-critical decision logic under unit test. No hardware, no ML models, fully offline.
